MIDI hex strings for Allen & Heath Soft Keys. By DoDo7. Copyright (c) 2026 Edoardo Montagnoli. All rights reserved.

Allen & Heath consoles take Soft Key MIDI messages as hexadecimal bytes. AllenKey writes those bytes for you: choose the message, the channel and the values, then copy the Press and Release strings.

How to use it

  1. Choose Note, CC or Program.
  2. Choose the MIDI channel, 1 to 16.
  3. Set the note or controller and the values. The strings update as you type.
  4. Type the bytes into the Soft Key on the console, or press Copy and paste the string into the editor software. The editor wants the bytes separated by commas, the default.

Editing the hex side

The two sides follow each other: change the controls and the hex updates, change the hex and the controls update.

  • Drag a hex character up to increase it, down to decrease it. On a data byte, the first character moves in steps of 16 and the second in steps of 1. With the keyboard, use the arrow keys.
  • On the first byte, the first character sets the message type and the second sets the channel.
  • Click or tap a byte to type it. Type or paste a whole string, such as B3 14 7F, to decode it. On a computer you can also paste anywhere on the page.
  • Dimmed characters are fixed by the message: for example the release velocity of a note is always 00.

Reading the bytes

Most messages are three bytes, xx yy zz. The first byte holds the message type and the channel, the second the note or controller number, the third the velocity or value.

First byteMessageBytes
8nNote Off3
9nNote On3
BnControl Change3
CnProgram Change2

n is the channel minus one, in hex: channel 1 is 0, channel 10 is 9, channel 16 is F. So Note On is 90 on channel 1 and 9F on channel 16.

Worth knowing

  • Note names follow the common convention where Middle C is C4 = 60 = 3C. Some software calls the same note C3; the number is what counts.
  • Some receivers treat Note On with velocity 0 as Note Off. Use it if the other end ignores 8n messages.
  • Program Change is only two bytes and has no release message.
  • Quick anchors: 10 = 0A, 16 = 10, 64 = 40, 100 = 64, 127 = 7F.
  • The colour mode and the byte separator are remembered. Everything else starts from its default each time AllenKey opens, with note C-1 (0).
